# 手机与 Mac 日程衔接

手机与 Mac 连接同一个 AI Bro 同步账号后，移动日程通过已有 notes 协议交换。配套 Mac 构建将这些日程显示在原生日程中心，Mac 创建或修改的安排也会生成对应的移动日程记录。旧版 Mac 应用不包含此适配器，需要本轮源码构建。

## 保留的数据

日程标题、开始/结束时间、时区、全天标记、地点、备注、所属项目、来源、提醒提前量、重复间隔、星期、次数/截止、排除日期、单次完成状态、取消与恢复。通知授权和通知内容隐私选项仍属于各设备，不会被另一台设备更改。

支持每隔若干天、周或月重复；每周可选多个星期。手机导入的 ICS 保留原件规则；Mac 能解析的规则可在原生日程中心编辑，超出 Mac 解析范围的复杂规则会在日程页提示并保留原记录，不会静默变成单次日程。

## 保存与冲突

- 稳定标识：Mac 的原始日程 ID 只用于生成稳定 wire ID，不依赖标题匹配；手机记录往返时保持原 ID。
- Mac 在 agenda.json 中同时保存日程和已确认的同步基线。原生日程文件没有就绪时不写入。
- 单端修改自动衔接；两端都改同一日程时，在 Mac 日程页显示两个版本，提供“保留 Mac 版本 / 使用同步版本”。可展开完整详情后选择。
- 写入前核对原 note 内容，经过现有工作区持久化流程确认，再更新同步基线。保存失败、返回丢失、写入过程中本地再次编辑都不会无条件覆盖。
- 从工作区删除日程记录会取消对应 Mac 日程。取消与恢复用记录状态传播，保留历史身份。

## 本轮证据

- `tests/agenda-sync.swift`：14 项转换/创建/双向编辑/冲突/取消恢复/无确认重试/小数毫秒检查。
- `tests/agenda-sync-store.swift`：实际 AgendaStore 文件重开、基线保存、并发编辑保护、冲突选择和失败写入保护。
- `tests/native-agenda-sync.test.cjs`：只读查询、CAS、整批拒绝、保存失败回滚及保留用户新编辑。
- `mobile/tests/agenda-native.test.js`：调用 Swift 编译和运行真实日程引擎，手机展开结果逐项对照每周、隔周、月底、DST 缺失钟点及全天事件。
- `mobile/tests/mobile.spec.js`：手机日程页面编辑 Mac 规则后，下一次重复日期仍正确。

本轮配套 Mac 构建：`mobile/build/desktop-agenda/AI Bro.app`；新版 iOS 包：`mobile/build/ios/AI-Bro-0.1.0-unsigned.ipa`。以上是代码与构建验证，真实双端页面、通知送达仍需设备验收。
