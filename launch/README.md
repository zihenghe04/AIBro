# AI Bro launch page

Bilingual static product page for AI Bro. Chinese is the default; `?lang=en` selects English. The page includes actual application screenshots, a 106-second film in both languages, six explorable workflows, course/research/personal use cases, local-project and model controls, and distribution links.

## Local preview

Serve `dist/` using a local HTTP server, for example `python3 -m http.server 18941 --directory dist`. No build or package installation is needed. Assets are self-contained; no external fonts, analytics, or content CDN are required.

## Content and privacy

All application screenshots and films use isolated fictional workspaces. Film model responses are scripted, while the interactions and saved data use the actual app. The films are edited and do not demonstrate model quality or request latency. The page does not collect user data or include credentials.

The layout takes inspiration from NVIDIA Cosmos 3's narrative structure. NVIDIA's code, branding, typefaces, videos, and proprietary media are not included.

The source repository is public; platform requirements and release status are listed in the installation guide. See the linked distribution and cloud-sync guides for platform requirements and current limitations.
