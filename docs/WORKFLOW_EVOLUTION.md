边界：本阶段审阅的是知识库笔记与资料元数据。尚不是任意本地文件写入、Office 二进制编辑或 Git diff。已有 PDF、Office 文字提取与图片处理，不等于所有音视频和数据库已可理解。

### 第二阶段 B 补充：对话产出（2026-09-14）

- A persistent, collapsible “Conversation files” shelf above the composer collects local proposals and library file changes from the conversation’s saved run history. Pending items appear first; library entries are deduplicated and reflect the current draft status. Local proposals keep their individual review snapshots, including dismissed and undone entries.
- Clicking a local proposal opens that exact proposal in the reader. Library entries open the current file, with a separate change-review action.
- Explicitly saving a newly created local file stages its versioned reference in the originating conversation. Undo removes that reference. Later reference versions and explicitly excluded files are preserved, and original message snapshots remain unchanged.
- Pending proposals can be dismissed after a failed run or disconnected directory; dismissal uses the same transaction lock but never accesses or writes the original file. Applying edits still requires an eligible run and connected project.
- Validated with unit tests, real filesystem/HTTP tests, and isolated native window QA with a synthetic model transport. This does not establish live-provider model quality.

### 第二阶段 C / 第三阶段 A：代码文本与受控终端（2026-09-14）

- 在已有连接目录中，代码与配置文本（Python、JS/TS、Swift、JSON/YAML/TOML 等）沿用完整读取、不可变提案、Diff、逐项保存与冲突检查。代码仅作为源码展示，不在预览中执行。Office 二进制编辑与新建目录仍未实现。
- Agent 通过 `knowledgeRequests: [{type: "terminal", argv: [...], cwd: "", timeout: 60}]` 提出命令。服务端保存不可变的程序、参数、目录身份和超时，前端审批只发送该记录 ID，不能在批准时替换命令。
- 审批栏展示实际 argv、实际工作目录与运行范围。普通命令始终逐次审批；本批允许记住的固定检查为 `pwd`、Git 版本、Git 简短状态与禁用外部 diff/textconv 的 diff 统计。Git 禁用 pager/fsmonitor、全局与系统配置；白名单绑定连接、目录身份和完整 argv，可从记录撤销。
- 没有隐式 shell 展开；命令以净化后的环境运行，不继承 App API 凭据。终端不是操作系统沙箱，用户批准的程序仍有本机权限；不能承诺其文件写入可由 Diff 撤回。
- 真实合并 stdout/stderr、退出码、失败、停止、超时和截断状态持续记录。单轮最多 8 条命令、单条最多 120 秒、输出保存上限 64 KiB（显式标明截断）。当前执行串行，不把分页/截断误报为完整结果。
- Agent 获得真实结果后继续推理。停止对话会停止当前命令；撤销连接会终止运行；宿主退出时监护进程终止命令进程组。主动脱离进程组的程序不受进程组取消保证，未实现 OS 沙箱。
- 重启不重放 pending/running 命令，保留中断记录并要求核对实际影响。历史输出可查看。失败提示区分“尚未执行”和“已有命令产生效果”。
- 验证包括真实进程与 HTTP、参数不可替换、目录替换、环境隔离、非零退出、超时、取消、授权撤销、白名单撤销，以及原生窗口中的审批 → 执行 → 结果送入后续模型请求。模型传输在验收中使用隔离替身。

### 后续第四阶段 A：结构化科研 Wiki（历史规划；现已实现）

- 条目类型：论文、方法/概念、实验、失败经验、review 反馈、研究问题与想法；每项有稳定 ID、来源、关联项目、版本和更新时间。
