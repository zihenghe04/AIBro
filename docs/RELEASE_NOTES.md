# AI Bro 0.10.0 开发预览版

从 [本版 Release](https://github.com/zihenghe04/AIBro/releases/tag/v0.10.0) 下载 Mac Apple Silicon 安装包。需要 macOS 14+，采用未公证的 ad-hoc 签名。

本版的重点是“今天”。打开 AI Bro 先看到今日页：今天的日程、到期的任务、昨天没做完的和已过期的，一眼看清该做什么。在今日页的输入框里写一句话（如“明天下午三点开组会”），就会自动识别成日程或任务，确认后加入；规则能解析的直接解析，不确定时才请模型辅助，并校验结果后再让你确认。

每天默认 08:30 生成当天简报，由 AI 撰写一段概览；没有配置模型、离线或调用失败时，会退回按规则整理的部分并给出提示。简报时间可以修改，也可以随时关闭。提醒、待审批、任务完成各有一个不同的提示音，可以单独开关。今日页与简报相关的选项都放在 设置 → 通知与提醒。

修复了英文界面下，侧栏、顶部连接状态和灵动岛里的项目名仍显示中文的问题。

本版不包含新的移动端安装包，Android 0.4.9 APK 仍在 [v0.9.4 Release](https://github.com/zihenghe04/AIBro/releases/tag/v0.9.4) 提供。详见 [更新日志](../CHANGELOG.md) 和 [安装说明](DISTRIBUTION.md)。
