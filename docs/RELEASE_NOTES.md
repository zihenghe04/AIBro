# AI Bro 0.9.8 开发预览版

从 [本版 Release](https://github.com/zihenghe04/AIBro/releases/tag/v0.9.8) 下载 Mac Apple Silicon 安装包。需要 macOS 14+，采用未公证的 ad-hoc 签名。

本版重点是界面一致性、多模型和删除体验：设置页可获取模型列表并保存多个模型（显示名、窗口、思考等级），对话中可直接切换；新增三套主题（蓝灰、中性灰、青绿），与浅色/深色外观相互独立，外观可跟随系统；删除对话和内容（含批量与“移入回收站”）不再弹确认，改为可撤销，撤销提示不会被后来的提示顶掉；侧栏入口改为“总览/对话”，新增 ⌘N 新对话；冷启动不再先闪主题色或浅色；宽窗口下浏览器能回到网页。同时修复了试用中发现的问题：浮层切页不关闭、设置行点不到、消息菜单四项无效、首次配置后测试连接误报“方案切换中”、入门引导无法收起。面向开发者的工具注册表与本机 MCP 也随本版加入。

本版不包含新的移动端安装包，Android 0.4.9 APK 仍在 [v0.9.4 Release](https://github.com/zihenghe04/AIBro/releases/tag/v0.9.4) 提供。详见 [更新日志](../CHANGELOG.md) 和 [安装说明](DISTRIBUTION.md)。
