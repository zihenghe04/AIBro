AI Bro connects conversations, project files, editable knowledge, and tasks in a local-first desktop workspace.

### Download / 下载

- **Apple Silicon Mac · macOS 12+**: download the `macos-arm64-preview.zip`, extract it, and move `AI Bro.app` to Applications.
- Includes Python and PDF runtime; Node.js, Python, and Homebrew do not need to be installed separately.
- Preview is ad-hoc signed, **not Apple-notarized**. Native Liquid Glass requires macOS 26.
- Custom API connections are configured in the app. OpenAI account sign-in requires a separately installed official Codex CLI.
- 中文：解压后将 App 移到应用程序，正常退出旧版再替换。已有本地资料保留；首次打开可能需要在 macOS 隐私与安全性中允许本次应用。

### Included / 功能

- Daily, course, and research projects with persistent conversations and source-linked knowledge.
- File intake, one main Markdown note per topic, editable notes, side-by-side reading, and task follow-ups.
- Project knowledge Q&A, per-conversation model and reasoning selection, prompt refinement, and activity visualizations.
- Chinese / English UI, onboarding, light / dark appearance, and optional self-hosted sync.

### Verification / 校验

`SHA256SUMS.txt` covers the release assets. `release-manifest.json` records the build and runtime versions. A corresponding source archive is provided alongside the App. Third-party dependency licenses and sources are documented in `THIRD-PARTY-NOTICES.txt`; PyMuPDF/MuPDF is AGPL/commercial software.

### Demonstrations / 演示

- `AI-Bro-Launch-zh-CN.mp4` / `AI-Bro-Launch-en.mp4`: 106-second product films, recut with stable close-ups and readable results.
- Matching `.srt` / `.vtt` subtitles are provided. Films are attached after visual and privacy review.
- The bilingual launch page source is in `launch/`, with workflow exploration and self-contained web films.

The films use isolated fictional workspaces and scripted model responses. They show real app interactions and persistence, with edited pacing; they are not model quality or latency benchmarks. No personal workspace, credentials, real papers, or account details are used.

This is a public macOS preview. Intel/Windows/Linux downloads, automatic updates, and Apple notarization are not included.
