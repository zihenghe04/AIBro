# AI Bro 0.9.11 开发预览版

从 [本版 Release](https://github.com/zihenghe04/AIBro/releases/tag/v0.9.11) 下载 Mac Apple Silicon 安装包。需要 macOS 14+，采用未公证的 ad-hoc 签名。

本版的重点是设置。原来分散的设置页合并成主窗口里的一页：左边是分类（通用、灵动岛与快捷入口、语音与听写、模型与连接、通知与提醒、同步与知识库、权限与安全、插件），右边是内容，随窗口宽度自适应；旧版设置页已移除。灵动岛的设置、菜单和语音入口会直接跳到对应分类，切换界面语言或主题后设置里的文字立即跟着变。

语音方面新增“听写到光标处”：单独按右 ⌥（或右 ⌘）、或自定义组合键，按住说话、松开后把文字输入到任意应用的光标处，默认开启，缺少辅助功能权限时会给出提示；听写时刘海下方显示带音量条和实时文字的小胶囊。大小写锁定键不再被误当作按住的修饰键。灵动岛展开和通知位置更稳，若干出场动画和流式文字显示更顺。

修复了空白快速录入草稿误报未保存、设置窄窗口下面包屑被裁切、英文界面残留中文等问题。

本版不包含新的移动端安装包，Android 0.4.9 APK 仍在 [v0.9.4 Release](https://github.com/zihenghe04/AIBro/releases/tag/v0.9.4) 提供。详见 [更新日志](../CHANGELOG.md) 和 [安装说明](DISTRIBUTION.md)。
