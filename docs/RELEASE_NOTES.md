# AI Bro 0.9.10 开发预览版

从 [本版 Release](https://github.com/zihenghe04/AIBro/releases/tag/v0.9.10) 下载 Mac Apple Silicon 安装包。需要 macOS 14+，采用未公证的 ad-hoc 签名。

本版的重点是模型设置和语音识别。设置 → 模型按“文本生成 / 嵌入 / 语音识别 / 使用统计”分段，左边是列表、右边是详情，页面底部有“完成”按钮；添加供应商只需选预设卡片并填密钥，也可以从 CC Switch 导入（缺密钥的会标“待补密钥”，之后补上即可）；测试连接时会自动识别接口协议；聊天里的模型选择器按服务商分组，选了哪个服务商就用它自己的地址、密钥和接口格式发送。ChatGPT 账号登录改由 AI Bro 自己完成（OAuth，令牌保存在钥匙串），会列出账号下真实可用的模型，错误分类也更具体。

语音识别合并成一份配置，在设置页管理：支持 ElevenLabs Scribe（云转写和实时转写都支持），支持自部署的 OpenAI 兼容服务（包括 http/ws 明文地址）；实时转写边说边出字、说完自动结束，实时失败时回退到云转写；密钥只写不读。

本版还加入插件管理（浏览器作为第一个插件，也可以导入外部 MCP 服务器，工具默认需要你批准）和计划任务（人工提醒与自动任务，后台内核可选 API 或 Codex CLI）。修复了日程页主按钮颜色、过期日程提案的“重新生成”、插件导入按钮、设置里下拉框被重复包住、PDF 选区偏移、Wiki“更多”面板溢出，以及凭据写入失败时的报错文案。

本版不包含新的移动端安装包，Android 0.4.9 APK 仍在 [v0.9.4 Release](https://github.com/zihenghe04/AIBro/releases/tag/v0.9.4) 提供。详见 [更新日志](../CHANGELOG.md) 和 [安装说明](DISTRIBUTION.md)。
