# AI Bro 0.9.6 开发预览版

从 [本版 Release](https://github.com/zihenghe04/AIBro/releases/tag/v0.9.6) 下载 Mac Apple Silicon 安装包。需要 macOS 14+，采用未公证的 ad-hoc 签名。

本版重点是 PDF 深度阅读和稳定性：PDF 工具栏可以「问这一页」，框选图表、表格或公式直接提问，打开引用原文时会在页面上标出被引用的文字，划词的解释、翻译与批注可以存为阅读笔记。灵动岛折叠态会按当前状态显示并随内容变形。对话里删除后可以撤销，生成中按 Esc 即可停止。浏览器网页在多轮对话之间保持打开。修复了启动约 10 秒后可能崩溃的问题。

本版不包含新的移动端安装包，Android 0.4.9 APK 仍在 [v0.9.4 Release](https://github.com/zihenghe04/AIBro/releases/tag/v0.9.4) 提供。详见 [更新日志](../CHANGELOG.md) 和 [安装说明](DISTRIBUTION.md)。
