# AI Bro 0.9.4 开发预览版

从 [本版 Release](https://github.com/zihenghe04/AIBro/releases/tag/v0.9.4) 下载 Mac Apple Silicon 安装包与 Android 0.4.9 APK。Mac 需要 macOS 14+，采用未公证的 ad-hoc 签名；Android 沿用开发签名。

本版加入各用途独立 API 方案、语音连接测试与经批准的 Mac→手机加密配置分享，修复录音转写保存闪退，并改善移动端草稿和键盘流程。Mac 可调用另行安装的官方 Claude Code CLI；这不代表手机 OAuth 或订阅转移已经可用。

iOS 源码随附，但当前安装与完整键盘验收未完成，不提供可安装 IPA。合成场景验证不代表全部真实账号、麦克风与实体设备均已验收。详见 [更新日志](../CHANGELOG.md)、[安装说明](DISTRIBUTION.md) 和 [移动源码说明](../mobile/README.md)。
