# AI Bro 0.9.9 开发预览版

从 [本版 Release](https://github.com/zihenghe04/AIBro/releases/tag/v0.9.9) 下载 Mac Apple Silicon 安装包。需要 macOS 14+，采用未公证的 ad-hoc 签名。

本版的重点是新的执行内核：对话里的每一次写入、删除和命令都经过同一套审批规则；关掉主窗口后，已开始的执行可以在后台继续，需要审批时通过系统通知或主窗口右下角的“后台运行”面板处理；长任务在上下文接近上限时自动压缩早期过程并保留原文引用，压缩阈值按模型的上下文窗口调整。设置 → 模型里可以试用“原生”工具调用方式，模型能并行调用多个只读工具。

权限方面：设置 → 自动化权限新增“后台运行权限”（默认跟随主窗口权限，可改为每个写入都审批或只读），删除类的后台步骤始终要在主窗口批准；“完全访问”下可撤销的删除（移入回收站）直接执行，永久删除等不可恢复的操作仍需批准。同一轮既删除又新建时，结果卡会同时列出移入回收站的内容并能直接打开回收站。另外修复了首次启动时侧栏停在“总览”而页面是设置页的问题。

本版不包含新的移动端安装包，Android 0.4.9 APK 仍在 [v0.9.4 Release](https://github.com/zihenghe04/AIBro/releases/tag/v0.9.4) 提供。详见 [更新日志](../CHANGELOG.md) 和 [安装说明](DISTRIBUTION.md)。
