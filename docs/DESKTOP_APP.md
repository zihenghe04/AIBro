# AI Bro 桌面 App

项目现在只交付一个桌面应用：`AI Bro.app`（Electron）。浏览器中打开 `app/index.html` 仅用于轻量预览，不是另一个 App。

Electron 壳加载项目自己的前端并自动启动同目录的 `server.py` 回环服务。解析 PDF、PPTX、DOCX、XLSX 和调用 OpenAI Responses API 都通过这个本地服务完成。工作区数据保存在用户目录 `~/Library/Application Support/ai-workstation`，应用升级不会主动删除它。

## 开发运行

```bash
npm install
npm start
```

`npm start` 使用项目内安装的 Electron。若依赖尚未安装，也可以显式指定已有 runtime：

```bash
ELECTRON_BIN=/path/to/Electron npm start
```

## 构建 macOS App

```bash
npm run app
```

macOS 26 原生玻璃组件可单独运行 `npm run native:build` 构建。它只调用公开的 AppKit `NSGlassEffectView`，不使用私有样式。启动与打包都会尝试编译；缺少 SDK 或 Node-API 头文件时会使用网页材质。可设置 `NODE_INCLUDE_DIR` 指向 `node_api.h` 所在目录。

在支持的 Mac 上，可使用项目 Electron 运行 `tests/native-glass-smoke.cjs` 和 `tests/native-glass-app-smoke.cjs`。这些验收使用临时用户目录和合成工作区，阻断外网及模型调用；前者检查原生区域生命周期和点击穿透，后者检查完整应用入口、外观切换、阅读区及窗口缩放。

产物为项目目录中的 `AI Bro.app`。构建脚本支持 `ELECTRON_APP=/path/to/Electron.app` 指定 Electron bundle，也支持 `AI_WORKSTATION_OUT_APP=/path/to/output.app` 指定输出位置。首次打开若 macOS 提示来源未验证，在 Finder 中右键选择“打开”。

联网时可以使用 electron-builder 生成 `dist/` 发行目录：

```bash
npm run dist
```

## 当前发行限制

- GitHub Release 提供 Apple Silicon 预览 ZIP，`npm run release:mac` 和 CI 工作流负责打包、测试及校验；详见[安装与构建](DISTRIBUTION.md)。暂不含自动更新或其他平台发行包。
- Release 发行包内置 Python 和 PDF 依赖。源码开发版仍需要 Python，可用 `AI_WORKSTATION_PYTHON` 指定。
- Release 内置 PyMuPDF，支持 PDF 预览与图表提取；模型接收原件或页面图像由连接能力决定。
- 当前构建为本地 ad-hoc 签名，没有 Apple Developer ID 公证；首次运行可能显示“无法验证开发者”。
- 桌面 API Key 已使用系统加密存储；首次使用或构建更新后，macOS 可能要求本人完成钥匙串授权。网页端配置保存在当前浏览器。

请勿同时启动多个应用副本。它们会共享工作区目录，多个进程写入时可能产生端口或状态竞争。

## OpenAI 账号登录

在“设置 → 连接方式”选择“OpenAI 账号登录”，点击“使用 OpenAI 账号登录”，在系统浏览器完成认证后返回应用。模型列表由当前账号返回。也可以继续使用原有的自定义 Responses API 配置，两种连接分别保存。

该功能使用官方 Codex CLI 的 app-server 接口；需安装可用的 Codex CLI。运行时优先从系统安装路径发现，也可设置 `AI_WORKSTATION_CODEX_BIN` 指定程序。应用仅使用自己的 `codex-auth` 目录，不读取或覆盖其他 Codex/NewMax 登录信息。登录凭据不进入页面、工作区导出或模型代理请求。

账号连接当前接收文本与图片。PDF 原件先保存，页面图像用于账号通道的多模态读取；自定义 Responses API 优先发送原始 PDF。两种通道均不重复发送已经以原件或页面图像提供的全文文本。后台文字索引用于项目检索，不阻塞发送。账号通道的 Office 文件仍使用文字兼容，尚未实现原版式多模态输入。项目内支持有预算的关键词分块检索与部分引用页跳转；大规模语义检索仍需完善。

在输入框旁可为当前对话单独选择模型和推理强度，支持继承设置中的默认值。切换从下一条消息生效；已发出的请求保留自己的实际配置。2026-09-11 已在正式 App 的两个独立对话中验证 gpt-5.6-sol / low 建库和 gpt-5.6-luna 查询同项目已有知识。

该集成使用官方运行时管理登录和刷新，不借用其他应用的认证文件。没有经过核实的“绑定 Codex 即可避免封号”保证；不能将运行时选择表述为防封策略。

网页版与桌面版共用 `app/asset-manifest.json` 的资源清单；设置底部显示构建指纹，桌面启动时只复用相同指纹的本地服务。更新后需正常退出并重启现有 `AI Bro.app`，无需另建第二个 App。

## 对话与执行进度

发送时，正文及附件快照进入消息记录，本次输入框与待发附件清空。历史原件仍保留在对话和项目里；普通追问检索已有资料，不自动重发整份 PDF。需要重新读原件时，可在历史附件旁选择“再次附加”。重试使用失败原轮的附件，不覆盖新输入的草稿。

对话内显示真实读取阶段、服务实际返回的公开摘要、工具状态和本地执行结果。未返回公开摘要的模型仅显示真实等待阶段；不模拟推理内容。生成没有总时长或静默超时限制，可手动停止；明确网络和服务错误仍会显示。文件解析、登录初始化、连接测试等操作的超时与生成阶段分开。

执行历史可单条或批量删除终态日志，不删除对话与生成内容；运行中及待审批日志不可删。回收站支持多选永久删除和清空，显示不可逆确认，并继续保护仍被引用的受管文件。

## 并排阅读

项目文件树、消息附件与来源链接可直接打开右侧阅读区。笔记、PDF 和图片共用阅读标签；切换 PDF 标签保留页码，放大阅读区或收起后可以回到原来的工作区。窄窗口改为单独阅读视图，提供返回入口。只保留活动文件的预览资源，切换、关闭及来源删除时取消旧加载；重新打开笔记时读取最新已保存版本。

### 灵活工作区（0.5.2）

- 拖动侧栏、对话列表与阅读区之间的分隔线调整宽度；方向键微调，Shift 加速，双击恢复默认。偏好保存在本机，缩小窗口不会覆盖原宽度。顶栏、侧栏底部和阅读区均提供外观切换；浅色模式使用玻璃风格的导航与浮动控制层，支持减少透明度/动画的系统偏好。macOS 26 配合已编译的原生组件时，主要控制区域使用 Apple 公开的 NSGlassEffectView；其他系统和网页使用 CSS 回退，正文保留实色。原生编译需要 macOS SDK 26 与 Node-API 头文件，可用 `npm run native:build` 检查。
- 点击对话输入框的「润色」即按已保存的配置处理，成功后直接替换草稿，并提供撤销。悬停约 0.65 秒，或点击旁边箭头，可选择表达风格、模型连接、独立模型与推理强度，设置自动保存。润色只发送当前草稿，不带历史附件、不执行任务；停止、失败或原草稿变化时不覆盖内容，变化时保留结果供复制。

### 长 PDF 附件（0.5.4）

OpenAI 账号通道已取消固定 60 页限制，后台读取所有页面并保留附件 ID 与页码，不再要求用户按页数手动拆分。145 页课件已验证完整准备。实际发送仍受连接的请求体、图片字节及模型上下文容量约束；超过实际容量会明确报错，不截断页码，也不自动重复发送全文文本。自定义 API 支持原生 PDF 时继续发送原文件。

### 课程归属核对（0.5.5）

现有课程清单只作为候选，不能仅凭主题相关、名称相似或“这门课”自动合并。未绑定且缺少明确归属证据的附件计划，若会写入已有课程，整份计划先显示归属确认，包括隐式归档来源和同名课程复用；操作权限的自动执行设置不替代课程身份确认。用户明确的新课程名优先于旧绑定和历史 AI 判断。确认前项目或附件归属变化时，旧计划取消，避免覆盖手动更正。

“移动 / 归属”会将同原项目下的来源分析笔记和任务一起迁移，原有课程的其他内容保留。历史结果卡片、归属概要、相关对话按现有记录展示，原始执行历史保持不变。
- 可将文件直接拖到对话区域上传，也可粘贴图片。绑定项目的对话会先保存原件到项目并标记待分析，附件随下一条指令交给 AI；自动判断入口留待后续 Agent 分类。直接拖到项目区仅保存原件，不创建对话或触发模型。文件夹需展开后选择文件，拖入其他区域不会跳离应用。
- 各空间和项目可手动添加任务，在详情中调整空间、项目、状态、优先级、开始与截止日期。时间线提供移动入口。移动保留原材料引用和清单，不移动外部原文件。
- 全局、空间和项目总览提供真实任务完成环图、项目进度、共享日期轴时间线与可点击的项目归属结构。日期不完整时只显示已知的开始/截止点；未排期任务不会被虚构工期。开始日期进入增量同步投影。

阅读标签是当前窗口的临时视图，不代表复制或移动文件；关闭标签不删除资料。笔记修改继续通过编辑器保留历史版本。任务属性和不可逆操作的确认仍使用对话框。

### 原件与分析状态

文件保存、文字索引和 AI 分析是三件独立的事。项目树、资料列表和阅读区均显示“待 AI 分析”或“已分析”；只有真实模型成功执行、保存了有来源关联的分析笔记或论文时才标记已分析。单纯重命名、归属、解析、生成任务，以及失败、待审批、本地基础整理不算 AI 分析。已分析不等于人工审阅。

项目页显示待分析资料数量；点击“交给 AI 分析”，会在该项目新建整理对话、带上选中原件并准备指令，用户补充后发送。已有草稿和附件不会被覆盖。原件未复制，分析结果通过来源 ID 关联；删除所有分析产物后，该资料恢复待分析标记。分析记录随资料增量同步。

### 连续对话修改任务（0.5.3）

创建待办后，可以继续说“截止改到明天下午3点”“标记完成”或补充名称、详情、优先级和检查清单。Agent 使用本轮任务清单中的原 ID 执行 `update_task`，保留未修改的字段和来源；独立待办无需项目或附件。

相对日期按消息发送时的本地日期和时区计算，重试保留原轮日期锚点。对话上下文优先包含最近成功操作及本会话任务，绑定项目时限定该项目，避免通用关键词带入其他项目的任务。目标不明确时需要澄清。

任务结果卡直接显示当前状态与截止时间，点击可手动编辑。审批摘要显示修改前后的日期；等待模型或审批期间任务若被手动修改、移动或删除，旧计划取消，不覆盖新内容。该功能不依赖重新上传附件或重新分析原件。


### 对话链接与科研自动归属（0.5.6）

直接发送论文或网页 URL，工作站会获取原件并将资料关联到该条已发送消息，然后交给模型分析。arXiv 的 abs/pdf/html 视图自动定位 PDF；显式版本会保留。已保存的相同链接在重试时复用，下载失败会明确显示原因；不会将空白资料当作全文分析，也不会将获取结果放回新草稿。

OpenAI 账号主对话可使用官方网页搜索；官方 OpenAI API 主对话声明 `web_search` 工具。兼容第三方 API 的主对话仍可读取用户提供的公开链接，但不会默认把官方搜索工具参数发送给它。提示词润色不启用搜索。用户明确要求不联网时停止自动链接读取和搜索；“请求批准”模式会在本轮读取/启用搜索前询问。搜索活动、可用来源链接和实际附件处理过程留在对话中。

科研项目由 Agent 根据论文与已有项目目标判断；有合适项目时匹配，没有合适项目时以独立科研资料入库，无需用户先声明。课程身份核对规则继续独立适用。论文去重优先 DOI/arXiv/URL；独立保存不会继承当前课程项目，已存在论文保留原项目和人工修订。未核验分析不等于人工审阅。

链接读取仅访问公网 HTTP(S)，每次跳转重新验证并限制完整下载大小；超过容量明确报错，不静默截断原件。PDF 原件优先保存，不等待全文文字索引；网页正文超出提取长度时标记不完整。需登录、验证码或仅客户端渲染的网站可能无法从公开读取获得正文。

### 文档组织与阅读（0.5.6）

- 每篇论文、每讲课程、每个日常主题默认维护一篇 Markdown 主笔记，章节取代碎片文件；可执行任务和原件保持独立关联。
- 全部内容默认可按文件树浏览，独立资料也有目录；保留列表/卡片、筛选和批量操作。
- 选择同空间、同项目的多篇笔记，预览后合并；论文固定主笔记，不同论文拒绝误并。原件、来源和历史保留，次笔记移入可恢复回收站，旧结果链接可跳主笔记。
- 阅读区可切换阅读、Markdown 编辑、并排预览和章节目录，支持 Cmd/Ctrl+S；保存等待本机数据库确认，切换/关闭前处理未保存稿。
- AI 补充既有笔记先保存待合并草稿，不覆盖人工正文。论文下载包与 Markdown 导出包含人工修订。
- 网页工具已验证真实搜索事件和来源，运行环境仍不暴露本机命令、文件或应用控制。


## 自定义 API 凭据与重启

桌面版将自定义 API 连接使用 Electron 系统加密存入固定用户数据目录下的 `credentials/api.json`，与工作区数据库、导出文件和云同步分开。保存后输入框留空表示使用当前服务已保存的凭据。重启或本地服务端口变化不要求重新填写；换到不同服务来源时不能沿用旧凭据。

填写但未点击“保存设置”的 Key 只用于当前测试/发送，界面会显示“尚未保存”。保存失败会保留输入并显示原因；系统加密不可用时不会退回明文磁盘存储。浏览器版本仍在当前浏览器中保存自己的 API 配置，不会通过工作区同步桌面凭据。

缺少 API 地址、模型或 Key 时，本轮消息保留并可重试，不会静默切换成本地整理或自动创建事项。连接测试只检查模型列表，实际支持的附件和调用格式需要模型请求验证。

### 首次使用与新手引导

启动时会提供一次五步引导：连接模型、添加材料与对话、空间和项目、主笔记与阅读区、任务总览。可以跳过，之后从“设置 → 新手引导”重新打开。引导操作已有界面，不生成示例数据，不自动提交材料或修改权限；右下方“下一步”和左右方向键可浏览，Esc 关闭。

### macOS 钥匙串授权

启动只检查加密凭据文件是否存在，不初始化 safeStorage，也不解密密钥。测试连接、发送 API 请求或保存连接时，系统才可能要求本人完成钥匙串授权。未验证时界面不会宣称 Key 已可用。旧版本浏览器保存的 Key 只在用户实际使用或保存该地址的连接时迁移，成功前保留旧值。

本地临时签名的构建在更新后可能再次触发 macOS 授权；面向公开发布需要使用稳定的代码签名身份。不要通过降低钥匙串保护或把 Key 写回明文来处理此问题。
